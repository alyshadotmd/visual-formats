# Comment Response Format — Visual Execution SOP

## What this format is, visually

A question posed through an Instagram or TikTok comment-response sticker (the question-sticker mechanic), acknowledged and answered by a real-seeming person, built so nothing in it reads as an ad. The viewer isn't being addressed directly, they're reading (or watching) someone else's exchange. That only works while it stays visually native. **The one property to protect: the whole frame has to look like a real sticker exchange, never a produced ad.**

**This visual identity is constant no matter what the reply argues or which awareness stage it's written for.** Whether the reply is agitating a brand-new problem or handling a skeptic's last objection, the sticker mechanic, the casting, and the native feel don't change. The script owns the question and the argument; this file owns how it looks while that argument plays out.

## Where the response sticker comes from (pick one)

- Instagram question / comment-response sticker (the black-bar prompt plus white question box). The original AMA form.
- The TikTok equivalent comment-response sticker.

A screenshotted real comment is a *different* format (see `comment-screenshot`). This format is always the question / comment-response sticker, never a plain comment bubble.

## How the reply is delivered (pick one)

- **Static / text-overlay:** free-placed native text over a selfie, POV, or lifestyle image.
- **Video:** the creator reads or references the sticker question on camera and their spoken response is the ad.

## Sticker bar (visual convention)

The format's convention is a black-pill sticker bar sitting above the white question box (or TikTok's equivalent), matched exactly to the platform's real sticker chrome, never a lookalike graphic. What the sticker bar actually says (its 2-5 words of copy) is scripted content owned by the script SOP; this file only governs that it exists, where it sits, and that it must match real platform styling. One emoji max, styled the way the platform itself would render it, never "FAQ" styling.

## Casting and setting

- Selfie, mirror selfie, POV product-in-hand, or lifestyle shot. The person is **mid-life, not mid-ad**, no studio, ring light, or podcast mic. Match the setting to the persona's actual day.
- **Peer answers peer:** the answerer must be castable as someone the asker would really ask. If the viewer wouldn't put this question to this person, the ad is miscast regardless of copy.
- Product in frame optional. If present, held like an object, not presented like a prize.

## Styling levers (visual/brand system)

The reply overlay's font and highlight-box color are a brand lever, not a default:

- **Bold sans in highlight boxes** reads casual and native. **Bold italic** adds energy. **Elegant serif** reads considered and premium, right for health/beauty/wellness.
- **Tint the highlight boxes with the brand's accent color** to tie the ad in without breaking the native feel. Keep contrast high and the text legible at thumb size.
- Whatever the treatment, the words still have to read like a person typed them. Styling makes it on-brand; it never makes processed copy pass.

## Video variant (visual/production only)

- **Show the sticker, then answer it.** Open by surfacing the question / comment-response sticker, then respond. The viewer must see or hear what is being answered within the first 2 seconds.
- **Casting and setting:** same rules as above, peer answers peer, mid-life not mid-ad. Front-camera selfie, talking head, or POV. No studio polish.
- **Keep text overlay as reinforcement, not a script.** A short on-screen caption of the question (and optionally a one-line verdict) helps sound-off viewers, but the spoken answer carries it. Never paste the full reply on screen and read it word for word.
- Captions on throughout.

## Design handoff

Question box in the top third (it's the hook and gets read first). Reply blocks placed with visible gaps, never one wall of text, alternating alignment is fine. CTA pill only on brand-cast ("us" sticker) or warm-retarget builds. For video: the response sticker anchored in the first beat, captions on.

**Production gauge:** if the designer has to shrink the type to fit, the copy is too long, that's a script-side problem, send it back rather than shrinking type to compensate.

## QA checklist (visual/production only)

- [ ] The source is a real question / comment-response sticker (Instagram's or TikTok's), matched exactly to platform styling, not a screenshotted comment
- [ ] Casting passes the peer-answers-peer test for this specific question
- [ ] Setting reads mid-life, not mid-ad, no studio polish
- [ ] Product (if present) held like an object, never presented to camera
- [ ] Styling (font, highlight color) matches the brand system and stays legible at thumb size
- [ ] Reply blocks have visible gaps, not a wall of text
- [ ] (Video) Sticker shown/named within the first 2 seconds; captions on; full reply not read word for word from an on-screen script
- [ ] Screenshot test: dropped into a stories feed with no context, nothing about the visual reads as an ad before the brand mention
