# Comment Response Format — Implementation SOP

## Reference examples (look here first)

To find examples, look in the shared `../../files/` folder for any file whose name contains `vf=comment-response`.

**Whenever this SOP is triggered or referenced, study the example creatives before shooting.** Use them to calibrate the sticker styling, the casting, and the native visual feel. They are the visual source of truth for what a passing Comment Response ad looks like.

## What this format is

A question posed through an Instagram or TikTok comment-response sticker (the question-sticker mechanic), acknowledged and answered by a real-seeming person, built so nothing in it reads as an ad. The viewer isn't being addressed directly, they're reading (or watching) someone else's exchange. It works because that framing only holds while it stays visually native — a sticker exchange reads as real life, not as marketing. This visual identity is constant no matter what the reply argues or which awareness stage it's written for: whether the reply is agitating a brand-new problem or handling a skeptic's last objection, the sticker mechanic, the casting, and the native feel don't change.

Strongest for **native-feeling Q&A moments that plant a reply inside someone else's exchange rather than addressing the viewer directly — myth-busting, objection handling, and any argument the script wants delivered peer-to-peer.**

The one property to protect: **the whole frame has to look like a real sticker exchange, never a produced ad.**

## Inputs

Expect a **messaging angle** (owned by the script SOP) — the question, the reply copy, and the awareness stage the argument is pitched at. On top of the angle, the brief must supply:
- **Platform** the sticker comes from: Instagram question/comment-response sticker or the TikTok equivalent.
- **Delivery mode:** static/text-overlay reply over a selfie, POV, or lifestyle image, or a video where the creator reads/references the question on camera and responds.

The script owns the question and the argument; this SOP governs how it looks while that argument plays out.

## Anatomy

1. **The response sticker:** the question/comment-response sticker itself (Instagram's black-bar-plus-white-box, or TikTok's equivalent), presented as the thing being answered — never a screenshotted comment, which is a different format (`comment-screenshot`).
2. **Sticker bar:** a black-pill bar sitting above the white question box (or TikTok's equivalent), matched exactly to the platform's real sticker chrome, never a lookalike graphic. What the bar says (its 2-5 words) is scripted content; this format only governs that it exists, where it sits, and that it matches real platform styling. One emoji max, styled the way the platform itself would render it, never "FAQ" styling.
3. **The reply:** free-placed native text overlay, or the creator's spoken on-camera response.
4. **Product (optional):** held like an object in frame, never presented like a prize.

### Video beats (in order)
1. Surface the question/comment-response sticker. What is being answered is the hook: the viewer sees or hears it first.
2. The creator responds on camera (peer answers peer, mid-life not mid-ad setting).
3. A short on-screen caption of the question (and optionally a one-line verdict) reinforces for sound-off viewers — never the full reply pasted and read word for word.
4. Captions on throughout.

## Build rules (priority order)
1. **The source must be a real platform sticker**, matched exactly to Instagram's or TikTok's own chrome, never a lookalike graphic or a screenshotted comment.
2. **Peer answers peer.** Cast the answerer as someone the asker would really ask; if the viewer wouldn't put this question to this person, the ad is miscast regardless of copy.
3. **Mid-life, not mid-ad.** Selfie, mirror selfie, POV product-in-hand, or lifestyle shot; no studio, ring light, or podcast mic. Match the setting to the persona's actual day.
4. **Reply blocks need visible gaps.** Never a wall of text; alternating alignment is fine.
5. **Styling ties to brand without breaking native feel.** Tint highlight boxes with the brand's accent color; keep contrast high and legible at thumb size.
6. **(Video) Open on the sticker as the hook, then answer it**; keep on-screen text as reinforcement, not a script.
7. **If the copy doesn't fit, that's a script problem.** If the designer has to shrink type to fit, send it back rather than shrinking type to compensate.

### Styling levers (brand system)
The reply overlay's font and highlight-box color are a brand lever, not a default:
- **Bold sans in highlight boxes** reads casual and native.
- **Bold italic** adds energy.
- **Elegant serif** reads considered and premium, right for health/beauty/wellness.

Whatever the treatment, the words still have to read like a person typed them. Styling makes it on-brand; it never makes processed copy pass.

## Length caps

| Element | Cap |
|---|---|
| Sticker bar copy | 2-5 words |
| Emoji on sticker | ≤1 |
| On-screen question caption (video) | 1 short line |
| On-screen verdict caption (video) | ≤1 short line |

## Build steps

1. Read the brief: the question, the reply copy, and the awareness stage from the script SOP.
2. Choose the platform (Instagram or TikTok) and the delivery mode (static text-overlay or video).
3. Source or build the real platform sticker; place it in the top third (it's the hook and gets read first).
4. Cast the answerer so they pass the peer-answers-peer test; choose a mid-life setting.
5. Place the reply: text-overlay blocks with visible gaps, or shoot the on-camera response opening on the sticker as the hook.
6. Style the reply (font, highlight-box color) to the brand system while keeping it legible at thumb size.
7. Add a CTA pill only on brand-cast ("us" sticker) or warm-retarget builds.
8. Claims pass: reply copy specific and validated, no absolutes or banned phrases.
9. Screenshot test: drop it into a stories feed with no context and confirm nothing about the visual reads as an ad before the brand mention.
10. Deliver: sticker platform and copy, reply (overlay copy or shot video), casting/setting note, styling spec, claims flags.

## QA checklist
- [ ] The source is a real question/comment-response sticker (Instagram's or TikTok's), matched exactly to platform styling, not a screenshotted comment
- [ ] Casting passes the peer-answers-peer test for this specific question
- [ ] Setting reads mid-life, not mid-ad, no studio polish
- [ ] Product (if present) held like an object, never presented to camera
- [ ] Styling (font, highlight color) matches the brand system and stays legible at thumb size
- [ ] Reply blocks have visible gaps, not a wall of text
- [ ] (Video) Opens on the sticker as the hook; captions on; full reply not read word for word from an on-screen script
- [ ] Screenshot test: dropped into a stories feed with no context, nothing about the visual reads as an ad before the brand mention
