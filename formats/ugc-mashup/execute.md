# UGC Mashup Format — Implementation SOP

## Reference examples (look here first)

To find examples, look in the shared `../../files/` folder for any file whose name contains `vf=ugc-mashup`.

## What this format is

A UGC video cut together from **several different creators'** clips into one ad, where no single clip carries a specific format on its own.

Strongest for **social-proof-heavy angles, "everyone's saying it" moments, and launches** that need breadth of voices rather than one deep story.

The one property to protect: **two or more different creators have to actually appear and be cut together** — one creator's clip is UGC, not a mashup.

## Inputs

Expect a **messaging angle** (the shared message or offer every clip should echo) and three or more creator clips to cut from. The angle sets what unifies the clips; this SOP governs the cut.

## Anatomy

1. **The creator clips:** two or more different creators' raw footage.
2. **The cuts:** quick hand-offs splicing the clips together.
3. **The unifying message:** matching captions or one shared line across clips.
4. **The close:** one shared CTA or offer at the end.

## Build rules (priority order)

1. Collect 3-6 creator clips on one message.
2. Cut fast between them so they build on each other.
3. Unify captions and end on one CTA or offer.
4. **Specific, real claims; no absolutes or banned phrases.**

## Length caps

| Element | Cap |
|---|---|
| Creator clips | 3-6 |
| Seconds per clip | ~3-5s |

## Build steps

1. Read the brief: angle/message, the creator clips available.
2. Select 3-6 clips that echo one message.
3. Cut fast between clips for quick hand-offs.
4. Unify the caption styling across clips.
5. End on one shared CTA or offer.
6. Claims pass.
7. Deliver: clip selection, cut order, caption style, CTA, claims flags.

## QA checklist

- [ ] Two or more different creators appear
- [ ] The clips are cut together into one piece (quick hand-offs between people)
- [ ] Creator-style footage, not brand production
- [ ] Honest claims; no absolutes or banned phrases
