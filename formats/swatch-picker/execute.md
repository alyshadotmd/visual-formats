# Swatch Picker — Implementation SOP

## What it is

A cursor clicks through color swatches like on a product page, and the product photo swaps to each color.

## Build rules

1. Recreate a simple product page selector; the swatches must look clickable.
2. Cut quickly between colors, one per click, so it feels like browsing.
3. Put the offer or hook above the selector so it stays on screen the whole time.
4. One message, one offer or CTA.

## QA checklist

- [ ] The device carries the message
- [ ] It reads at a glance on a phone
- [ ] Honest claims; no absolutes or banned phrases
