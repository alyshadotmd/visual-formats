# Challenge Format — Implementation SOP

## What this format is

A contest or stunt with one simple rule, filmed as it happens. The viewer stays to see the result, and the result is often the deal.

## Build rules (priority order)

1. State the rule in the first 2 seconds, on screen and out loud ("every second = 1% off").
2. Show progress visibly: a timer, a counter, the % going up.
3. Keep a host or commentator to raise the energy.
4. End on the outcome and the offer it unlocked, then the product.

## QA checklist

- [ ] The rule is clear in the opening seconds
- [ ] Progress is visible on screen
- [ ] The ending pays off the challenge and lands the offer
- [ ] Honest claims; the final offer matches what's actually available
