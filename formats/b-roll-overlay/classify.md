# B-roll Overlay — Classification Guide

(Named by Alysha and promoted from the parking lot, 2026-09-30. Media: video.)

## Reference examples (look here first)

To find examples, look in the shared `../../files/` folder for any file whose name contains `vf=b-roll-overlay`.

## Definition

A video made only of **b-roll footage** (product, hands, lifestyle shots) with **text overlaid** to carry the message. No voiceover and no one talking on camera.

## The things that must all be true

1. **Only b-roll footage.**
2. **Text overlay carries the message.**
3. **No voiceover and no one talking to camera.**

## Quick test

Mute it and nothing is lost, and nobody talks on camera? If yes, B-roll Overlay.

## Commonly confused with

- **Instagram Text Overlay:** if the text is Instagram's own native story text, that more specific format wins alone. Never pair the two.
- **UGC:** needs a person on camera.
- **Unboxing:** someone opens a package.

## Signals

Hands, product close-ups, lifestyle cutaways, designed or plain captions, music only.
