# Yapper Format — Visual Execution SOP

## Reference examples (look here first)

- **Reference examples:** They live in the shared `../../files/` folder, tagged `vf=yapper`.
- **Whenever this SOP is triggered or referenced, open the shared `../../files/` folder (filter for `vf=yapper`) and watch the examples first** — the framing, the energy level, the pacing/cut rhythm, and how none of it looks staged.

## What this format is, visually

A creator talking fast and direct to camera in a way that reads as a **spur-of-the-moment rant, a yap sesh, a FaceTime call** — something a real person just posted, not something a brand produced. One person, direct address, minimal setup, no b-roll crutch.

**This visual identity is constant no matter what the script says or which awareness stage it's written for.** Whether the argument underneath is agitating a brand-new problem or handling a warm retarget's last objection, the way it's shot and performed doesn't change: it always has to look like it was filmed in the moment, on a phone, by the person actually saying it. The script owns *what* is argued and *in what order*; this file owns *how it looks and feels* while that argument is delivered.

**The one property to protect: it has to look and sound like a real, unscripted moment.** The instant it looks lit, staged, or produced, or the energy sags, the format stops working, no matter how good the underlying script is.

## Visual signature

- **Framing.** Handheld or propped selfie-style, native phone-camera feel. Explainable in one phrase: held at arm's length, propped on a counter, set on a dash. If you can't say where the phone is sitting, it isn't native.
- **Setting.** A real, ordinary environment the moment would actually happen in, a bedroom, a car, a bathroom mirror, a kitchen. Never a set or a backdrop built to look like nothing.
- **Eye-line.** Direct to lens, sustained. This is a person talking to a friend through the camera, not reading a teleprompter past it.
- **Lighting.** Reads native (window light, bathroom light, car interior), never an obvious ring light or studio rig.
- **Continuity feel.** One continuous take, or jump-cuts that feel like breath/pause removal from a single real sitting, never a multi-scene edit that reads like a shoot.
- **Energy.** Fast, high, sustained end to end. No lulls, no dead air. This governs performance regardless of whether the underlying script is agitating a problem or closing a warm retarget.
- **Text overlay convention.** The format's convention is a caption/overlay layered over the direct-to-camera shot for at least the first 3 seconds, styled like something the person would slap on their own post (plain, lowercase-feeling, no title case). This file governs that it belongs on screen and how it should look; what it actually says is scripted content, owned by the script SOP.
- **Product handling.** If the product appears, it's held or used the way a person handles a thing they actually own, never presented to the lens or posed next to a screen. That reads as ad-brain and breaks the format instantly.

## QA checklist (visual/production only)

- [ ] Framing reads native (phone camera, explainable placement), not a rig
- [ ] Setting is a real, ordinary environment, not a set
- [ ] Direct eye-line sustained throughout
- [ ] Lighting reads native, not produced
- [ ] Edit feels like one sitting (single take or breath-cut jump cuts), not a multi-scene shoot
- [ ] Energy is high and sustained end to end, no lulls
- [ ] Overlay/caption present on screen for at least the opening beat, styled like a real caption
- [ ] Product (if present) is handled naturally, never presented to camera
- [ ] Captions burned in

## Production handoff

Tight framing, direct eye-line, punchy cut rhythm if cutting at all, overlay placed and timed per the script's hook, high energy sustained end to end, captions on. Hand the script (from `../../../script-swipe-file/formats/yapper.md`) to whoever is filming, this SOP is what turns those words into something that looks real regardless of which awareness stage that script was written for.
