# Text Echo Format — Implementation SOP

## Reference examples (look here first)

To find examples, look in the shared `../../files/` folder for any file whose name contains `vf=text-echo`.

## What this format is

One phrase repeated in big stacked lines, with the product in front. It works because repetition is satisfying and hypnotic to look at, and it hammers a single message so hard there is nothing else to read. Built for thumb-stopping at a glance.

Strongest for **sales and offers ("25% Off", "Sale"), launches ("New"), and any moment where one short phrase is the whole message.**

The one property to protect: **one phrase only.** Adding a second message breaks the rhythm.

## Inputs

Expect a **messaging angle** that boils down to 1-3 words, and the hero product.

## Anatomy

1. **The repeated phrase:** 1-3 words, stacked 3-6 times, full width.
2. **The product:** one hero SKU, often hand-held, in front of the type.
3. **Background:** soft and neutral so the type reads.
4. **One small supporting line:** optional ("Black Friday Sale").
5. **Brand mark.**

## Build rules (priority order)
1. **Pick one short phrase** and repeat it exactly.
2. **Go huge.** Each line should run nearly edge to edge.
3. **Let the product overlap the type** so it feels layered, while the phrase still reads.
4. **Keep everything else tiny** or cut it.
5. **Honest offer and claims.** No absolutes or banned phrases.

## Length caps

| Element | Cap |
|---|---|
| Repeated phrase | 1-3 words |
| Repeats | 3-6 lines |
| Supporting line | ≤4 words (optional) |
| CTA | 0-1 |

## Build steps

1. Read the brief: the phrase and the hero product.
2. Set the phrase in a bold, clean font; stack it full width.
3. Shoot or place the product so it overlaps the type.
4. Add the small supporting line and brand.
5. Claims pass; thumb-size check that the phrase reads instantly.
6. Deliver: phrase, repeat count, font direction, product placement.

## QA checklist
- [ ] One phrase, repeated exactly, stacked
- [ ] Type is huge and full width
- [ ] Product overlaps without killing legibility
- [ ] Everything else tiny or gone; honest; no absolutes/banned phrases
