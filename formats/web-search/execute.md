# Web Search Format — Implementation SOP

## Reference examples (look here first)

They live in the shared `../../files/evergreen/` and `../../files/bfcm/` folders, tagged `vf=web-search`. Study them first.

## What this format is

An ad **made to look like an internet search** (Google-style search bar, search history, autocomplete suggestions). The searches voice the viewer's problem, and the product shows up as the answer.

## Build rules (priority order)

1. Write 3-5 searches in the viewer's own words, from general to painfully specific.
2. Make the search UI look real (bar, icons, suggestion rows).
3. Put the product right under the search as the answer.
4. One short line tying the product to the searches.

## QA checklist

- [ ] A search bar or search results mockup is the hero
- [ ] The searches voice a real problem or question the viewer has had
- [ ] The product is presented as the answer
- [ ] Honest claims; no absolutes or banned phrases
