# Bento Grid Format — Implementation SOP

## Reference examples (look here first)

They sit in the shared `../../files/evergreen/` and `../../files/bfcm/` folders, matched by the `vf=bento-grid` token. **Study one first** — notice how the tiles mix image types (product, lifestyle, text) yet lock to the same alignment, palette, and type.

## What this format is

A static or video built as a **tile layout that mixes image types** (product shots plus at least one lifestyle, in-use, macro, or footage tile, often with a text panel) into one composed frame. Like a bento box holding different foods, the mix is the point; tile sizes can be equal or varied. It works because a clean, curated composition signals quality and craft, and because mixed tiles let one ad carry several messages (product, detail, lifestyle, proof) without feeling busy.

Strongest for **collection launches, brand-story and heritage, editorial / lookbook moments, and multi-message stories** that need more than one idea in a single frame.

The one property to protect: **clean, aligned tiles that mix image types and read as one composed piece**. All flat product shots is product-grid; overlapping or scattered is collage.

## Inputs

Expect a **mix of assets** — a hero product shot, macro/detail crops, lifestyle imagery — plus the **copy points** for the text tile(s). The messaging angle decides what each tile argues; this SOP governs the composition.

## Anatomy

1. **The tile grid:** often 2x2 / 2x3; equal tiles or some merged/larger tiles for hierarchy.
2. **At least one non-flat-product tile (required):** lifestyle, model, in-use, macro crop, or footage.
3. **Product tiles:** hero product shot(s).
4. **Text tile (usual, not required):** title, offer, collection name, or bulleted proof points.
5. **Unifiers:** one palette, one type system, consistent gutters tying the tiles together.

## Build rules (priority order)

1. **Mix image types on purpose.** At least one tile must be lifestyle, in-use, model, macro, or footage; without it, it's a product-grid. Keep alignment and gutters tight.
2. **Usually include a text tile** carrying the message (title, offer, collection, or bullets).
3. **Unify with one palette and type system** so the varied tiles read as a single composition.
4. **Tile size is optional hierarchy.** Equal tiles work; a bigger hero tile can help but isn't required.
5. **Crop images intentionally** to their tile; embrace the framing.
6. **Keep it clean and aligned.** If tiles overlap or scatter, it's a collage, not a bento-grid.
7. **Honest claims.** Validate any proof points; no absolutes or banned phrases.

## Spec caps

| Element | Guide |
|---|---|
| Tiles | ~3-6 (equal or varied sizes) |
| Non-flat-product tiles | at least 1 (lifestyle / in-use / macro / footage) |
| Text tiles | usually 1 (title, offer, or bullets) |
| Palette | one unifying palette + type system |

## Build steps

1. Read the brief: the messages to carry and the assets available (hero, crops, lifestyle, copy points).
2. Choose a tile grid and assign hierarchy (which tile is the hero).
3. Place image tiles with intentional crops; place the text tile(s) with the title or bullets.
4. Lock one palette and type system; tighten gutters and alignment.
5. Add the brand lockup.
6. Claims pass (validate proof points).
7. Deliver: tile layout, per-tile asset/crop spec, copy for text tiles, palette/type notes, claims flags.

## QA checklist
- [ ] At least one tile is not a flat product image (else it's product-grid)
- [ ] The message is carried (usually by a text tile)
- [ ] One palette and type system unify the composition
- [ ] Hierarchy is clear (by tile size or placement)
- [ ] Clean and aligned — bento, not collage; claims validated
