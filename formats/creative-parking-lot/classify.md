# Creative Parking Lot — Classification Guide

(Set up by Alysha, 2026-09-30.)

## Definition

An umbrella tag for **specific creative executions** that are real and worth finding again, but too narrow to be a
primary visual format of their own (yet). The file gets two format tags: `creative-parking-lot` first, then the
execution's own name second, for example `vf=creative-parking-lot_vf=fortune-cookie`.

This is different from the creator-content parking lot, which holds *candidate primary formats* waiting to be promoted.
The Creative Parking Lot holds *specific executions* that live in the library as they are.

## When to use it

1. **The device is a specific object or trick**, not a broad way of building an ad (a fortune cookie slip, a highlighter
   marking up a printed page).
2. **No primary format already covers it.** If one does, use that format instead.
3. **It isn't just the look of the render.** Whether the photo is real, staged or AI-made doesn't decide the tag.

## Executions in the lot

| Execution | What it is | Example |
|---|---|---|
| `fortune-cookie` | The message printed on a fortune cookie slip, held in hand. | Dose, "Bloated? 3 bottles of Dose for your Liver is now 30% off" |
| `annotation` | A printed page of copy being marked up by hand (highlighter circles, underlines) as the video reads it. | Ryze, mushroom coffee script highlighted line by line |
| `cart-screenshot` | A screenshot of an online shopping cart or checkout page, with the BFCM discount showing in the cart totals. | Grüns, checkout cart screenshot with the offer on top (bfcm) |
| `swatch-picker` | A cursor clicks through color swatches like on a product page, and the product photo swaps to each color. | Hommey, "Save 35% off bedding bundles" (bfcm) |
| `doodle` | An original hand-drawn or line-drawn character or scene (often lightly animated) carries the ad, with a caption on top. | Magic Mind, crying brain under "Realizing I bought Magic Mind 1 day before the Black Friday sale..." (bfcm) |

## Promoting out of the lot

When the same execution shows up across several brands and starts to feel like a way of building ads rather than a one-off,
Alysha can promote it to its own format folder. Then drop the `creative-parking-lot` tag from its files.

See `execute.md` for how to use a lot execution in a brief.
