# Creative Parking Lot — Implementation SOP

## What this is

A holding place for narrow creative executions. Each one is a single device, so the brief is short.

## Build rules

1. Pick the execution from the table in `classify.md` and look at its example first.
2. Keep the device real and physical where it's meant to be (a real slip, a real printed page, a real hand).
3. Put the message on the device itself. The device is the hook.
4. One message, one offer or CTA.

## QA checklist

- [ ] The device carries the message
- [ ] It reads at a glance on a phone
- [ ] Honest claims; no absolutes or banned phrases
