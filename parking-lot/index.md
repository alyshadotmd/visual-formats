# Visual formats — parking lot

Candidate visual formats spotted in the wild, not yet promoted into the live library at [`../formats/index.md`](../formats/index.md).

Each candidate lives in its own folder here, mirroring the shape of promoted formats. When a candidate is ready, promote it: move the folder to `../formats/<name>/`, rename `candidate.md` into `classify.md` and spin out `execute.md`, migrate `files/` into `../files/` under the `vf=` naming, add the row to `../formats/index.md`, and remove the row from this file.

Reference files inside each candidate folder use `b=<brand>.<ext>` because the folder itself signals "parked".

## Parked candidates

- [`floating-product-layer/`](floating-product-layer/) — music/try-on video with a graphical product element composited in and floating over live footage.
- [`giant-product-tiny-people/`](giant-product-tiny-people/) — static of the product rendered at monument scale in a surreal staged scene, with miniature human figures interacting for scale and craft narrative.
- [`audio-message/`](audio-message/) — video staged as a personal voice/audio message to a specific named person, with word-by-word captions synced to speech; viewer overhears rather than being pitched.
- [`myth-vs-fact/`](myth-vs-fact/) — static split into a MYTH panel (red no-icon, common false belief) and a FACT panel (green check, corrective claim, usually a study stat); belief-correction contrast is the structure.

## How to use

- Add a candidate the moment you spot a pattern that doesn't match any existing format cleanly, even half-formed.
- Keep at least one real example reference: an inspo/ad-library link, and a saved reference file under the candidate's `files/`.
- Add more examples over time. Confidence to promote usually builds after seeing the same pattern 3-4 times across different brands.
- A candidate becomes a live format only when Alysha explicitly promotes it.
