# Visual formats — parking lot

Park candidate formats here while they're still forming. Nothing in this file is live or taggable. A format only becomes real when it's promoted into `../formats/index.md` with its own folder under `../formats/`, a `classify.md`, and an `execute.md`.

## How to use
- Drop a candidate in the table the moment you spot it, even half-formed.
- Keep at least one real example reference: an inspo/ad-library link, and a saved reference file under `./files/` when possible.
- Reference files here use `b=<brand>_p=<candidate-slug>.<ext>` so they read as "parked" rather than banked format examples.
- When a candidate is ready, promote it: add the index row, create the folder under `../formats/`, write `classify.md` and `execute.md`, migrate the reference media into `../files/` under the `vf=` naming, and delete its row here.
