# visual-formats

Creative strategy visual-format library.

If you want to see all of the formats, go to [runneth.com/alysha/visual-formats](https://runneth.com/alysha/visual-formats).

- **`formats/`** One folder per format, each holding a `classify.md` (how to identify the format) and an `execute.md` (how to build one). The definitions are shared by every season.
- **`files/`** Every example ad in one folder, year-round (`s=evergreen`) and Black Friday / Cyber Monday (`s=bfcm`), all named the same way. Naming rules, offer types, favorites and tag notes are in its `_index.md`. Every brand, its product category and its file tag are in [_brands.md](files/_brands.md).

Start with [index.md](formats/index.md).
